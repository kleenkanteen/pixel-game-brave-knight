## Destination

A build-ready spec for **Stage 1** (Play screen → knight rises → sword → wheat field → farmer) plus the **stage framework** that Stages 2–6 will plug into — nothing left to decide before someone builds it.

## Notes

- **Domain:** a small pixel-art side-scrolling game. Vocabulary lives in [`/GLOSSARY.md`](../GLOSSARY.md); use its terms (Stage, Brave Knight, Knight Width, Dialogue, Prompt, Interact, Strike, Objective).
- **Skills every session should consult:** `grilling` + `domain-modeling` (default); `codebase-design` for anything about module/slice boundaries; `prototype` for prototype tickets.
- **Standing decisions from charting** (settled with the user before the map existed):
  - **Stack:** Vite + plain JavaScript ES modules; one HTML page + CSS holding a `<canvas>`; Canvas 2D API. No frameworks.
  - **Fresh start:** no existing code is reused. The current "Witching Hour" diorama gets moved into `/legacy` (or ignored); the game lives at the repo root.
  - **Architecture:** vertical slices — one folder per feature (`title`, `intro`, `dialogue`, `player`, `sword`, `npc-farmer`, `objective`, `stage-1`) plus a thin shared `core` (loop, input, camera, scaling, asset loading). Exact seams are a ticket.
  - **Art:** *everything* drawn in code with the Canvas API — characters, props, scenery. No image assets, no Sprite Fusion.
  - **Resolution:** 320×180 internal, integer-scaled to fit the window, crisp pixels.
  - **View & controls:** side-view. A/D or ←/→ walk; W/↑ jump; Space = Interact; click = Strike (once sword held; animation only in Stage 1).
  - **Flow:** page shows fall graveyard scene with **Play** centred → click Play → birdsong (fetched from a **free API**) plays while the knight's Dialogue text is on screen, fading after → Brave Knight climbs out of the grave in front of the cross → **player can move as soon as he's out** → Dialogue types quickly: "Brave Knight: Huh? Where am I?", then "I thought I died in the war.", then **Next →** → click anywhere → "Objective / Explore" for 5 s.
  - **Sword:** lies beside the grave; Prompt "Press space to pick up" above the knight within 1 Knight Width; Space → held; then "Click to strike sword" above the knight for 5 s.
  - **World (left→right):** graveyard at far left, church centred in the first screen, fall trees (red/yellow/green leaves), wheat field 10 Knight Widths long **cut off by the right edge of the first screen**, then the farmer; the world ends at the farmer. Camera follows the knight, clamped at both ends.
  - **Farmer:** Prompt "Press space to talk" above the farmer within 1 Knight Width; Space → Dialogue "Farmer: In progress" typed the same way. Nothing further — no end card.
  - **Proximity rule:** every Prompt shows only while the horizontal gap knight↔thing ≤ 1 Knight Width, and hides again when he leaves.

## Not yet specified

- **Window & device edge cases** — resize/fullscreen behaviour, whether touch/mobile needs to work at all, focus loss/pausing.
- **Replay** — whether there's any way back to the Play screen after the farmer, or the page just sits there.
- **Stage framework contract** — what a Stage must expose so Stages 2–6 slot in (entry/exit, world bounds, transitions); sharpens out of the slice-boundaries ticket.

## Out of scope

- **Content of Stages 2–6** — no content defined yet; each gets its own map later.
- **Image/sprite assets & Sprite Fusion** — all art is drawn in code.
- **Combat** — Strike is an animation only; nothing to hit in Stage 1.

## Build status

- **Built:** Stage 1 happy path end-to-end — title/PLAY, birdsong (Wikimedia Commons, credit line), climb out of the grave mound, intro Dialogue, Objective "Explore", walk/jump, sword pickup + Strike, scrolling camera, farmer + "Farmer: In progress". Scenery painted in code (sky, parallax hills, fall trees, stone church, graveyard + cross, wheat cut off at x 320, falling leaves). All beats screenshot-checked (`tickets/assets/screens/beat-*.png`).
- **Run:** `npm install && npm run dev` · production: `npm run build`.
- **Shoot:** `npm run shoot` (see [`tools/README.md`](../tools/README.md)) — scripted playthrough → PNGs in `tickets/assets/screens/`, fails on page console errors.
- **Known limitations:** no replay after the farmer; no touch/mobile controls; no pause on focus loss; birdsong silent if Commons is unreachable; the farmer Prompt is nudged left at the world's right edge to stay on screen.
